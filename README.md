# Marcos Mariano

Web designer e desenvolvedor de sites em Itatiaia, RJ. Crio sites institucionais, landing pages e interfaces digitais com foco em clareza, responsividade e experiência de uso. Trabalho com WordPress, Elementor, HTML, CSS, JavaScript, Figma e Canva; também exploro ferramentas de IA em fluxos de criação e desenvolvimento.

## Projetos em destaque

- [Meraki — portfólio de web design](https://github.com/marcosbasilio/meraki-portfolio): apresentação visual de projetos e sites.
- [Portal editorial](https://github.com/marcosbasilio/portal-editorial): navegação editorial, busca e filtros com conteúdo fictício.
- [PalcoFlow](https://github.com/marcosbasilio/palcoflow-portfolio): painel de gestão com dados inteiramente fictícios.
- [Área de membros](https://github.com/marcosbasilio/area-de-membros-portfolio): interface pública sem cadastros ou dados reais.
- [Site institucional](https://github.com/marcosbasilio/site-institucional-portfolio): estrutura responsiva de apresentação de serviços.
- [Jardim Secreto](https://github.com/marcosbasilio/jardim-secreto): interface responsiva de inspiração botânica, sem dados ou integrações de produção.

As versões públicas de portfólio foram separadas dos projetos de produção para não expor credenciais, configurações privadas ou informações de usuários.
